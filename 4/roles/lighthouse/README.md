Lighthouse
=========

This role installs Lighthouse (https://github.com/VKCOM/lighthouse) and Nginx to work with it.


Role Variables
--------------

|vars|description|
|----|-----------|
|nginx_port| Version of Nginx to install|



Example Playbook
----------------

Including an example of how to use your role (for instance, with variables passed in as parameters) is always nice for users too:

    - hosts: servers
      roles:
         - { role: lighthouse }
